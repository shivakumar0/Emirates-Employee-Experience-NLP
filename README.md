# Emirates-Employee-Experience-NLP
A data science pipeline and NLP analysis exploring employee experience and workplace culture at Emirates Airline using YouTube comments. Covers data collection (YouTube API), 4-method sentiment labelling, text classification (Naive Bayes, Logistic Regression, SVM), and topic modeling (LDA).
